# PPM Sesi 2 - Product & Profile

Aplikasi Flutter sederhana: kartu profil mahasiswa (StatelessWidget), kartu produk
(StatefulWidget), tombol Favorite, pengatur jumlah (- / +), Tambah ke Keranjang (SnackBar),
dan banner promo (Stack + Positioned).


## Cara Menjalankan
```bash
flutter pub get
flutter run
```

## Widget yang Digunakan
Scaffold, AppBar, Row, Column, Container, Card, Stack, Positioned, Icon,
ElevatedButton, IconButton, StatelessWidget, StatefulWidget, SnackBar.
